# UI fonts (Bloom)

Bundled **Plus Jakarta Sans** (OFL license, [tokotype/PlusJakartaSans](https://github.com/tokotype/PlusJakartaSans)):

- `PlusJakartaSans-Regular.ttf` — body (14px)
- `PlusJakartaSans-Medium.ttf` — section labels (11px), tabs (12px)
- `PlusJakartaSans-SemiBold.ttf` — card titles (15px), active tabs (12px)
- `PlusJakartaSans-Bold.ttf` — menu title (22px)

Vanille searches `fonts/` next to the executable first, then falls back to embedded Verdana / Segoe UI.
